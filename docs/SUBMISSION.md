# Submission draft
**Title:** EcoMind AI — Explainable Environmental Interventions on a Graph
**Track:** Agents That Act on Connected Data
**Description:** EcoMind AI investigates connected environmental problems by traversing a FalkorDB knowledge graph of problems, causes, interventions and evidence. It ranks interventions with transparent, adjustable criteria and shows every query, relationship and missing-evidence gap. The demo uses a clearly labelled synthetic school-waste scenario.
**Technical novelty (claim only what's verified):** recommendations are derived from multi-hop causal chains with weight propagation, not from text generation; the agent can only run whitelisted, parameterised read-only Cypher; missing evidence is a first-class output.
**Before submitting:** run the integration tests on a live FalkorDB, record the demo, add your real GitHub URL. None of these were done by the assistant.

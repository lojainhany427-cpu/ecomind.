4. (1:00) Show the ranked recommendations and the score components. Drag the *Low cost* slider up and re-run: the ranking changes.
5. (1:20) Click *Student awareness campaign*: "No evidence in the graph — the system flags it instead of inventing support."
6. (1:40) Contrast: a plain chatbot gives a generic list; this shows which relationships justify each answer.
7. (1:50) Close: "Explainable, auditable decisions from connected data; FalkorDB multi-hop traversal at the core."
